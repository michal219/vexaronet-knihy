Otázky

Časté otázky

Jakého chatbota podle knihy postavím?

Asistenta na web, který odpovídá na běžné otázky zákazníků z vaší znalostní báze, přizná, když odpověď nezná, a nabídne kontakt na člověka. Stejný postup použijete pro jakoukoli malou firmu.

Kolik stojí provoz?

Claude Code vyžaduje placené předplatné Claude. Odpovědi chatbota se platí v Claude API podle spotřeby; v knize je orientační výpočet s uvedenými předpoklady a návod, jak nastavit limit útraty. GitHub a Cloudflare Pages mají bezplatné tarify. Aktuální ceny ověřte na webech služeb.

Může chatbot odpovědět špatně?

Ano, AI se může mýlit. Kniha proto staví na odpovědích jen z vašich podkladů, přiznání neznalosti, zákazu závazných slibů, cestě k člověku a pravidelném testování.

Potřebuju předchozí knihy?

Ne. Kniha obstojí samostatně. Pokud znáte naše předchozí díly, některé kroky projdete rychleji.
